Find SkillDocs docs matching `$ARGUMENTS`.

Use `skilldocs_find`. With no arguments it lists every section and what's filed
under each — do that first if `$ARGUMENTS` names a folder rather than a title,
so you use the section's real name rather than guessing.

Report each match with its title, section, `doc_id` and open comment count.
Don't open or modify anything; this is a lookup.
