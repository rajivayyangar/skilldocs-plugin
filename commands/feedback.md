---
description: Show what changed and what people said on a SkillDocs doc
argument-hint: <doc_id>
---

Read the feedback on SkillDocs doc `$ARGUMENTS`.

1. `skilldocs_diff` for what collaborators changed.
2. `skilldocs_comments` for the open threads.

Summarise both together, and point out where a thread is explaining an edit the
diff already shows — that pair is one piece of feedback, not two. Don't change
any files yet.

If `$ARGUMENTS` is empty, ask for the doc id.
